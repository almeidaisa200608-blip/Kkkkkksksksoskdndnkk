Projeto inspirado nas instruções e capturas de tela da atividade Alura.
Como abrir
Extraia o arquivo ZIP.
Abra index.html no navegador.
Passe o mouse ou toque nos cartões para virá-los e ver as respostas.
Arquivos
index.html: estrutura e conteúdo dos cartões.
styles.css: layout, cores, responsividade e animação 3D.
script.js: interação por toque e teclado.
O projeto é estático e não precisa de servidor ou instalação.
